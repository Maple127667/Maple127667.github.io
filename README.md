# Maple — Creative Developer Portfolio

A cinematic black-blue personal site for projects and editorial notes, built with React, Vite, and Three.js.

## Development

```bash
npm run dev
```

The hero is a real-time stochastic Three.js three-body system: every reset samples new 3D momentum, evolves into a chaotic collision, fragments, and magnetically reassembles. It respects reduced-motion preferences.
